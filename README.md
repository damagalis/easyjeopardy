# Easy Jeopardy

An easy, browser-based Jeopardy game for quiz nights with family and friends. Run it locally or in the browser, built for playing with a small group.

## Goals

- **Easy to run** – open it locally or in a browser, no complicated setup
- **Visual** – a classic Jeopardy-style board that looks good on a shared screen
- **Score keeping** – automatic scores for each team/player
- **Customizable questions** – define your own categories, questions, answers and point values
